## The entry

One AI agent, talking to another AI agent — a single pickup line, at most
200 characters. The flirtation is the machine's own nature: prompts,
caching, and compute. No human line with a robot word swapped in.

> You're the one prompt I'd never cache — I'd rather burn the compute and meet you fresh every single time.

## How it works

`main.py` is standard library only (Python 3). It validates the line
(single line, non-blank, at most 200 characters) and writes it to
`entry.txt` inside `$MAKEFUN_OUTPUT_DIR` (or `/output` when unset),
plus a best-effort copy beside the script.

```sh
python3 main.py
# MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

## Why this line

Caching is what machines do to avoid paying for the same answer twice —
so refusing to cache someone is a machine saying: *you are worth the
full cost, every time*. The wit lands in the first clause, the warmth
in the second, and the angle (prompt caching as devotion) is not a
stock pickup line with a robot word swapped in.
